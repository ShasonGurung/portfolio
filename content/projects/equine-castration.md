## The project

This research application supports veterinary case entry and follow-up surveys after equine castration. Its mobile client connects to an ASP.NET Core API and a PostgreSQL data model for cases, horses, owners and surveys.

## My contribution

- Developed React Native case-entry and survey forms connected to backend services.
- Extended the relational model and API to support owner, horse, case and survey relationships.
- Implemented survey eligibility and validation based on the case's discharge date.
- Worked with Expo Application Services on signed builds and mobile submission preparation.

The project required coordinated changes across the mobile interface, backend logic and data model.
